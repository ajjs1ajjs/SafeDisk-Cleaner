# Безпека SafeDisk Cleaner

SafeDisk Cleaner видаляє файли з правами користувача — ставтеся до нього відповідно.

## Що вже зроблено

- Видалення лише з підтвердженням і показом обсягу; системні шляхи та
  профіль користувача захищено сегментним матчером; симлінки ніколи не
  обходяться і не видаляються як цілі.
- Оновлення: обов'язкова SHA-256-перевірка, allowlist URL, підпис видавця,
  неможливі для вгадування тимчасові шляхи.
- Ланцюг: централізовані версії пакетів, lock-файли, SHA-піни CI-екшенів,
  блокуючий NuGetAudit (all, включно з транзитивними) + окремий
  інформаційний `dotnet list --vulnerable`, підписані релізи з
  per-asset `<asset>.sha256` (формат sha256sum, генеруються після
  підпису, покривають фінальні байти).

## Повідомити про проблему

Створіть приватний issue в репозиторії або напишіть мейнтейнеру напряму.
Не публікуйте експлойти у відкритих issues.

## Перевірка релізу перед запуском

```bat
certutil -hashfile SafeDiskCleaner-<ver>-setup-win64.exe SHA256
```

Звірте з відповідним `<asset>.sha256` у тому ж релізі. Незбіг — не запускати.
