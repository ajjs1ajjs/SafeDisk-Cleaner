# Changelog

## v1.1.0 — Огляд, фільтри, теми

**Нові сторінки та функції**

- **Dashboard «Огляд»** — нова головна сторінка: картки звітів (звільнено за весь час, карантин, останнє сканування), смуги зайнятості кожного диска та швидкі дії («Сканувати зараз», дублікати, карантин, audit, налаштування)
- **Фільтри кандидатів** у «Скануванні»: пошук за шляхом, фільтр за категорією та рівнем ризику, «Скинути фільтри», кнопка «Тільки безпечні»
- **Експорт звіту** про кандидатів у CSV або JSON
- **Повне очищення кошика Windows** прямо зі сторінки «Сканування» (команда існувала, але не була виведена в UI)
- Налаштування «У кошик» тепер доступне в інтерфейсі (раніше приховувалось)

**Безпека дублікатів**

- «Вибрати все» для дублікатів тепер завжди залишає **одну найновішу копію** кожної групи — неможливо стерти останню копію файлу

**Класифікатор**

- Нові категорії сміття: **Delivery Optimization cache**, **Windows Error Reporting**, **Internet cache (INetCache)**, **Prefetch files** (+ тести)

**Палітра та інтерфейс**

- **4 акцентні теми** (Cyan / Purple / Green / Amber) з живим перемиканням в «Налаштуваннях» — вся тема оновлюється миттєво
- **Світла тема тепер працює** (раніше тумблер нічого не міняв) — повна світла палітра разом із MaterialDesign
- Прибрано хардкод-кольори з Views — усе винесено в базову/акцентну палітри (динамічні ресурси)
- Confidence кандидатів тепер показується **міні-прогресбаром** замість пласкої плашки
- **Empty states** для Карантину та Audit Log
- Видалено мертві ресурси теми, шрифт — Segoe UI Variable, прибрано частину важких glow-ефектів

**Дистрибуція**

- Повернено **інсталятор** (Inno Setup, `SafeDiskCleaner-<ver>-setup-win64.exe`) — встановлення в `%LOCALAPPDATA%\Programs`, ярлик у меню «Пуск», видалення через «Програми та компоненти»
- Release тепер містить і портативну збірку, і інсталятор

## v1.0.0 — Стабільний реліз 🎉

Перший стабільний реліз. Усі можливості перевірені тестами (93 тести, включно з інтеграційними на SQLite), збірка автоматизується через GitHub Actions, а оновлення поширюються через GitHub Releases.

**Що було зроблено для 1.0**

- Повний перепис на **WPF + .NET 10 LTS**: MVVM, Dependency Injection, Generic Host, портативна single-file збірка
- Тема **Neon Clean**: неонові атри, світіння, заокруглені таблиці та кастомний заголовок вікна
- **Безпека як пріоритет**: захищені системні шляхи та розширення, атрибут SYSTEM, перевірка зайнятих файлів і нещодавнього використання, перевірка цифрових підписів Microsoft
- **Recovery System**: Кошик для малих файлів + Карантин із відновленням і терміном зберігання
- **Audit Log**: повний журнал дій (EF Core + SQLite)
- **Пошук дублікатів** за BLAKE3-хешем
- **Автооновлення** з GitHub: перевірка, завантаження, встановлення в один клік
- **CLI** для сценаріїв автоматизації (analyze / clean / duplicates / drives / audit / quarantine / update)
- **CI/CD**: GitHub Actions — збірка, тести, автоматична публікація release-артефактів

**Покращення стабільності до 1.0**

- Один невдалий файл більше не перериває все очищення
- Карантин безпечний навіть при збої запису до БД (rollback)
- Батчований запис аудиту — менше навантаження на базу
- Кешування перевірки цифрових підписів — значно швидший повторний аналіз
- Таймаути та сувора перевірка сертифіката в автооновленні
- Windows DriverStore більше ніколи не пропонується до видалення
- Очищення можна скасувати в будь-який момент

**Ліцензія**: MIT.

## v0.5.0 — Безпека та стабільність

**Безпека**
- Автооновлення: жорсткий 12-секундний таймаут запиту версії, суворіша перевірка сертифіката та перевірка SHA-256 завантаженого оновлення
- Файли з Windows DriverStore більше ніколи не пропонуються до видалення (це пакети встановлених драйверів)
- Перевірка "нещодавнього використання" тепер враховує і час запису (LastWriteTime) — NTFS часто не оновлює LastAccessTime

**Стабільність**
- Якщо запис карантинного запису до БД падає після переміщення файлу — файл повертається назад (не втрачається)
- Очищення карантину (Purge/Empty) більше не падає на заблокованих файлах
- Один невдалий файл більше не перериває все очищення; журнал аудиту батчиться (менше навантаження на БД)
- Очищення можна скасувати (кнопка скасування), кандидати позначаються коректно

**Продуктивність**
- Кешування перевірки цифрових підписів (значно швидший повторний аналіз)
- Виправлено потенційне зависання на великих журналах аудиту

**Інфраструктура**
- CI-пайплайн (GitHub Actions): збірка + тести + публікація release-артефактів
- Інтеграційні тести на реальному SQLite (карантин, аудит, end-to-end очищення)

## v0.4.1 — Виправлення очищення карантину

- Виправлено помилку EF Core "could not be translated" при очищенні простроченого карантину: SQLite не підтримує порівняння `DateTimeOffset` у SQL-запитах

## v0.3.0 — Повний перепис на .NET 10 / WPF

**Архітектура**
- Повний перепис з Tauri (Rust + React) на **WPF + .NET 10 LTS**
- MVVM (CommunityToolkit.Mvvm), Dependency Injection, Generic Host
- Layered архітектура: `SafeDiskCleaner.Core` / `Infrastructure` / `App` / `Cli`

**Стек**
- UI: MaterialDesignInXamlToolkit (Material Design 3), темна/світла тема
- Дані: EF Core + SQLite (audit log, карантин)
- HTTP: HttpClientFactory + Refit + Polly (Resilience: retry/timeout/circuit breaker)
- Логування: Serilog (async sink, rolling file)
- Валідація: FluentValidation
- Хешування дублікатів: BLAKE3
- CLI: `SafeDiskCleaner.Cli` з підкомандами analyze/clean/duplicates/drives/audit/quarantine/update

**Виправлені проблеми безпеки (порівняно з v0.2.6)**
- **Command injection** усунено: шлях до файлу більше не вставляється в PowerShell-скрипт, а передається через змінну середовища
- **Таймаут** для PowerShell `Get-AuthenticodeSignature` (10 с) замість вічного очікування
- Перевірка оновлень більше **не блокує** UI (async + Polly timeout)
- `PathProtection` канонізує шляхи — обхід через `..`/символічні посилання більше не пройде
- Виправлено вразливий `SQLitePCLRaw 2.1.11` → `2.1.12` (GHSA-2m69-gcr7-jv3q)
- Semver: підтримка pre-release тегів (`2.0.0-beta.1`)
- Переміщення у карантин між різними томами (copy+delete fallback)

**Тести**
- 89 unit-тестів (xUnit + FluentAssertions + Moq)

## v0.1.0

- Initial release: SafeDisk Cleaner MVP
- Scanner Engine: багатопотоковий обхід файлової системи (Temp, Crash Dumps, Browser Cache, Logs, Package Cache, Thumbnail Cache, Old Windows Install, Windows Update cache)
- Пошук дублікатів файлів (BLAKE3) з підтримкою в UI та CLI (`duplicates`)
- Реальний час сканування: прогрес по кожному кореню через Tauri events
- Confidence System: рейтинг безпеки кожного файлу (95-100 Safe / 80-94 Probably Safe / 50-79 Needs Review / <50 Do Not Touch)
- Safety Engine: захист системних шляхів, розширень (.dll/.sys/.exe/.cat/.inf/.msi/.msp), атрибутів, заблокованих файлів, рецентності використання
- Cleanup Engine: pipeline Find → Validate → Safety Check → Confirmation → Delete → Report
- Режими роботи: Analyze, Interactive, Auto, Dry Run
- Recovery System: малі файли → Кошик, великі файли → Карантин (C:\ProgramData\SafeDisk\Quarantine)
- Audit Log: повний журнал дій у JSONL
- Recycle Bin: підрахунок та очищення через Windows API (SHFileOperation)
- Tauri UI (React + TypeScript): аналіз, категорії, кандидати, дублікати, карантин, audit log
- CLI: `analyze`, `clean`, `duplicates`, `drives`, `audit`, `quarantine`, `update`
- 46 unit tests, нуль compiler warnings
- Перевірка оновлень через GitHub API
